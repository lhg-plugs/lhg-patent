# /lhg-patent:prior-art —— 现有技术检索指引

用户输入在 `$ARGUMENTS` 中：技术主题关键词（如"智能水杯 水温显示"）。

> ⚠️ **合规声明**：本指引帮你**系统地做检索**，但**检索结果不保证查全**；新颖性/创造性的最终判断请专利代理人做。

## 流程（加载 novelty-check 第 3 节）

### 1. 拆检索要素
把技术方案拆成检索要素：技术领域 + 核心特征 + 解决的问题。
每个要素准备 3~5 个同义词/上位词（如"显示"→"指示/提示/预警"）。

### 2. 构造检索式
```
（核心特征A OR 同义词A1 OR 同义词A2）AND（核心特征B OR 同义词B1）AND 技术领域
```
- 先宽后窄：先用上位词跑一遍看量级，再加限定收敛
- 分类号检索：找到最接近的 IPC 分类号，用分类号+关键词交叉验证

### 3. 检索源清单（按优先级）
1. 中国专利全文数据库（免费，母语优先）
2.  Espacenet / Google Patents（国际覆盖）
3.  非专利文献：学术论文、产品手册、众筹页面、电商上架记录（**公开发售也算公开**）
4.  标准/手册：行业标准中的相关技术描述

### 4. 记录与比对
输出 `prior-art.md`：
| 文献 | 公开日 | 公开了什么特征 | 与本方案的差异 |
每篇最接近的现有技术写清"差异点"——差异点就是创造性论述的素材。

### 5. 诚实声明（必须写）
```
本次检索覆盖：中国专利数据库、Espacenet、Google Patents，检索式见上。
声明：检索不保证查全，未发现不等于不存在；是否具备新颖性/创造性请专利代理人判断。
```

## 硬规则
- 不许写"检索过了，没有现有技术"——只能写"本次检索未发现"。
- 公开日早于申请日的**任何**公开形式（论文、产品、演讲）都算现有技术，别只查专利库。
- 检索式和检索过程要留档（供代理人复核）。
